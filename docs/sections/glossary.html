Begrippenlijst

DSGO
Digitaal Stelsel Gebouwde Omgeving, het afsprakenstelsel voor digitale informatie-uitwisseling in de gebouwde omgeving.
Gegevensverzameling
Zie de definitie van [=gegevensverzameling=] in [[[#achtergrond-woordenboek-ontologie-en-gegevensverzameling]]].
Informatiemodel
Zie de definitie van [=informatiemodel=] in [[[#achtergrond-woordenboek-ontologie-en-gegevensverzameling]]].
JSON
JavaScript Object Notation, een veelgebruikt uitwisselformaat voor data. Linked data kan in JSON worden uitgewisseld met de variant JSON-LD.
NEN 2660
Norm met regels voor informatiemodellering van de gebouwde omgeving. De norm bestaat uit twee delen, NEN 2660-1 en NEN 2660-2; deze richtlijnen bouwen voornamelijk voort op de NEN 2660-2.
OBT
Ontwerp-, bouw- en technieksector.
Ontologie
Zie de definitie van [=ontologie=] in [[[#achtergrond-woordenboek-ontologie-en-gegevensverzameling]]].
OTL
Object Type Library (en) of Objecttypenbibliotheek (nl). Term die in de bouwsector gebruikt wordt; deze richtlijnen vermijden de term omdat hij geen duidelijke definitie heeft.
OWL
Web Ontology Language [[owl2-overview]], bevat uitgebreidere mogelijkheden dan RDFS om een linked data-ontologie uit te drukken.
QUDT
Quantities, Units, Dimensions and Data Types Ontologies; vocabulaire voor eenheden en grootheden, gebruikt bij complexe eigenschappen.
RDF
Resource Description Framework. Zie [[rdf11-concepts]].
RDFS
RDF Schema, taal waarin je een linked data-ontologie kan uitdrukken [[rdf-schema]].
SHACL
Shapes Constraint Language [[shacl]], een taal om RDF-data te valideren tegen een set regels.
SKOS
Simple Knowledge Organization System. Zie [[skos-reference]].
Turtle
Een uitwisselformaat waarmee linked data kan worden uitgewisseld volgens deze W3C-specificatie: [[turtle]].
UML
Unified Modeling Language [[uml]].
Unique Name Assumption (UNA)
De aanname dat een ding maar één naam (id) heeft en dat verschillende namen dus verwijzen naar verschillende dingen in de werkelijkheid.
URI
Uniform Resource Identifier, de unieke identificatie van een resource op het web. Zie URI volgens W3C.
W3C
World Wide Web Consortium, internationale organisatie voor de standaardisatie van het web.
Woordenboek
Zie de definitie van [=woordenboek=] in [[[#achtergrond-woordenboek-ontologie-en-gegevensverzameling]]].
XML
Extensible Markup Language. Een uitwisselformaat waarmee data tekstueel kan worden uitgewisseld volgens deze W3C-specificatie: [[xml]].
